## Project memory

This workspace uses **Project Brain**. At the start of a session, read
`.project-brain/index.md` (small map of projects → topics → status). Drill into
`.project-brain/projects/<name>/<topic>.md` only for detail you actually need.
Before redoing work, check the map — if a topic is marked done, ask before repeating it.
After finishing a unit of work, update the topic file and its one-line entry in the index.
